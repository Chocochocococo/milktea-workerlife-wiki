    系統介紹

    此頁面將介紹奶茶勞工生活的各項系統，指令一覽請見此頁面。

    勞工系統介紹¶

    基本流程¶

    上工賺錢→採購收集原料→研發茶譜→調製飲品→飲用恢復活力→上工

    進階玩法¶

    在空閒時可以： 1. 去冒險 2. 去釣魚 3. 去玩大富翁 4. 在心湖撿石子 5. 照顧寵物與伴侶

    狀態值介紹¶

    1. 稱號：調製飲品獲得熟客點數，累積熟客點數至一定程度即可獲得稱號。
    2. 職業：分為基礎職業、一階職業與二階職業，各職業消耗的活力、獲得的原料與奶茶幣都不同。
    3. 經驗值：累積至一定程度才能轉職高階職業。
    4. 資產：持有的奶茶幣。
    5. 狀態：持有的活力，進行各項活動都需要活力。
    6. 紀錄：已解鎖的茶譜數量。
    7. 等級：你在冒險系統裡的等級。
    8. 攻擊力、防禦力：在冒險系統裡的攻擊力與防禦力。
    9. 武器：在冒險系統里使用的武器，後方數值為耐久度，每次攻擊都會消耗耐久度，消耗數值因武器而異。武器可在麵包店購買。

    交易系統¶

    官方商店¶

    官方商店會販售恢復活力值的食品、調製飲品的原料，部分原料僅能在官方商店購買。
    此外，官方商店也會收購多餘的原料，收購價為官方售價的一半，傳說原料的收購價則是解鎖冒險地點的茶譜要求數量。

    玩家市場¶

    玩家可以在市場上架或下架商品販售，若有收購需求，也能刊登收購請求。
    為了方便，也能透過攤位指令一覽你或指定玩家在市場上的商品與收購請求，並能使用商品ID指定購買或指定出售。

    倉庫¶

    玩家可以將重要物品存放進倉庫中。
    倉庫裡的物品可以在研發茶譜或調製飲品時使用，但不會因為冒險等意外事故掉落。 倉庫最多可放置15種物品，且不限數量。

    大富翁系統介紹¶

    特有的狀態值¶

    1. 行動力(AP)：擲骰所需的數值，每6分鐘恢復1點，上限為100點。

    不同功能的格子¶

    1. 地產類：可供投資的地產格子，投資後可向其他玩家收取過路費。
    2. 隨機事件類：隨機觸發幸運或不幸事件。
    3. 幸運格子：獲得奶茶幣。
    4. 不幸格子：損失奶茶幣。
    5. 商店格子：隨機販售一種功能性卡片（如：雙倍租金、免費通行、惡意破壞等）。
    6. 監獄格子：探監或坐牢。
    7. 拉斯維加斯：押大或押小，一夜暴富！
    8. 加盟店格子：開放全體玩家認購股份，路過時所有股東皆可獲得分紅。
    9. 奶茶店總部：起點，路過時可根據持有地產獲得分紅。

    玩法¶

    1. 花費20點AP擲骰，在地圖中前進。
    2. 踩到他人地產：支付過路費（可選擇是否發起惡意收購）。
    3. 踩到無主地產：選擇是否投資。
    4. 踩到自有地產：選擇是否升級。
    5. 或是踩到其他格子，觸發事件。
    6. 再次花費AP擲骰，在地圖中前進……

    特殊機制¶

    1. 付不出過路費時，將被判為破產並受到懲罰：  
    2. 持有地產隨機一處降一級，一級地產則會法拍成為無主地產。  
    3. 所有AP歸零，並送回起點。  
    4. 扣除10%活力。（沒有地產時，會扣除25%活力）  
    5. 衛生局會每週抽查等級最高的三處地產，被抽查的地產需要支付10%地產總值當公關費，無法支付時地產會降一級（一級地產會法拍成為無主地產）。
    6. 各伺服器的地圖是獨立運作的。

    冒險系統介紹¶

    地點與解鎖¶

    1. 不同的冒險地點（如牛奶銀河、奶茶店櫃檯、地下室等）棲息著不同的怪物與神獸。
    2. 需透過「研發茶譜」來解鎖新的冒險地點。

    戰鬥與神獸¶

    1. 遭遇怪物：可選擇攻擊、飲用飲料（補血）或逃跑。戰鬥中使用武器會消耗耐久度。
    2. 神獸挑戰：每個地點深處都有專屬神獸，挑戰成功可獲得「傳說茶譜碎片」。
    3. 傳說茶譜：集齊碎片後可習得該地點的傳說茶譜，解鎖該地點的「探索」功能。

    探索功能¶

    在已通關的地點進行探索，可觸發特殊事件並獲得稀有原料（如星塵糖粒、貓肉球冰塊等）。

    釣魚系統介紹¶

    釣具與準備¶

    1. 釣竿：分為多個等級，越高級的釣竿越容易釣到大型魚，且是挑戰傳說魚的必要條件。
    2. 餌料：消耗品，越高級的餌料越容易吸引稀有魚種。
    3. 智慧釣魚：可設定預設釣場與餌料，若庫存不足系統會自動選用背包中最強的配置。

    釣場與漁獲¶

    1. 釣場解鎖：從水溝開始，隨著總漁獲量增加，逐步解鎖下水道、溪流、湖泊、大海與深海海溝。
    2. 漁獲種類：包含淡水魚、海水魚、甲殼類、軟體動物以及各種奇怪的垃圾（或寶藏）。
    3. 傳說魚王：每個釣場都有一隻機率極低的神祕魚王，只有裝備精良的釣客有機會遇見。

    紀錄與排行榜¶

    1. 釣魚圖鑑：記錄玩家釣過的魚種與最大尺寸。
    2. 排行榜：可查詢特定魚種的伺服器紀錄（Top 20），或查詢「全魚種巨物總榜」與「釣魚經驗榜」。

    心湖漣漪系統介紹 (搶石子)¶

    觸發機制¶

    1. 活躍生成：伺服器成員聊天時，有機率在該頻道觸發心湖漣漪，掉落石子。
    2. 閒置喚醒：若伺服器長時間無人說話，系統會自動投放石子以活絡氣氛。
    3. 週期波動：系統會定期舉辦「心湖週期波動」，在指定頻道降下大量石子雨。
    4. 管理員指令：管理員可隨時手動召喚石子雨。

    石子與稱號¶

    1. 石子種類：分為小石子、方糖、心湖結晶，以及倒楣的「空回覆」與「違規內容」。
    2. 稱號系統：根據玩家撿到的石子種類與數量，給予趣味稱號。

    兌換商店¶

    1. 基礎兌換：將石子直接兌換為奶茶幣。
    2. 獎勵兌換：伺服器管理員可設定身分組或自訂獎勵（如繪圖、周邊），供玩家消耗石子兌換。

    玩家互動指令¶

    1. 召喚隕石：使用石子召喚五顆隕石，並從中選擇一顆拆解，可獲得方糖與心湖結晶的機率比心湖波動高。
    2. 呼喚石子雨：使用石子呼喚指定數量的石子雨，所有人都能隨意撿起石子雨，獲得方糖與心湖結晶的機率會比召喚隕石高。

    寵物與伴侶系統¶

    寵物系統¶

    1. 領養：可領養貓、狗或史萊姆。
    2. 互動：需定期餵食（喝飲料）、洗澡與玩耍，維持寵物的飽食、清潔與快樂度。
    3. 協助功能： ‧釣魚時：寵物會幫忙提升魚的尺寸，或撿回餌料（飢餓時可能會偷吃魚）。 ‧工作時：快樂的寵物偶爾會帶回隨機道具。
    4. 寵物旅館：忙碌時可將寵物寄養，凍結狀態數值避免生病或離家出走。

    伴侶系統¶

    1. 告白：向其他玩家發送告白請求。
    2. 互動：成為伴侶後，可以互相贈送道具、請客（恢復對方活力）。

    麵包坊¶

    專門販售冒險用的武器（法國麵包系列），從普通的法棍到傳說的黃金法棍，是增強冒險戰力的唯一途徑。
