短期效果可以透過[餵湖](../systeminfo.md#lake-offering)或[轉蛋](gachalist.md)獲得，會在大富翁或冒險中自動生效。

## 共通規則
1. 每個效果都有可用次數，生效一次就扣一次，次數用完就會消失。
2. 獲得後24小時內沒用完，效果也會過期消失。
3. 同一種效果不會疊加。已經有同一種效果時，會刷新有效時間，可用次數則取兩者中比較多的那個。
4. 餵湖時一次投越多顆供品，拿到的效果次數（或數值）可能越多。
5. 大富翁的效果可以在`/大富翁 狀態`查看；冒險的效果會在`/冒險 出發`時列出。
6. 正面效果和負面效果可以同時存在，遇到時兩者都會生效。

## 正面效果
| 效果 | 生效系統 | 效果說明 |
| --- | --- | --- |
| 🍬 糖分衝刺 | 大富翁 | `/大富翁 擲骰`的AP消耗減少50%。 |
| 🎫 甜蜜通行 | 大富翁 | 支付過路費時減免30%。 |
| 🌫️ 糖霧護身 | 大富翁 | 壞事件造成的損失降低50%。 |
| 🥤 甜味補給 | 冒險 | `/冒險 出發`的初始活力額外+10（餵湖獲得時數值可能不同）。 |
| 🍮 糖心護符 | 冒險 | 抵銷冒險中的1次物品損失。 |
| 🧊 糖霜護甲 | 冒險 | 冒險戰鬥受到的傷害降低40%。 |

## 負面效果
負面效果只會在餵湖說謊被奶茶神識破時染上。

| 效果 | 生效系統 | 效果說明 |
| --- | --- | --- |
| 😵 血糖驟降 | 大富翁 | `/大富翁 擲骰`的AP消耗增加50%。 |
| 💸 甜度加價 | 大富翁 | 支付過路費時額外加收5%。 |
| 🫗 苦味回甘 | 冒險 | `/冒險 出發`的初始活力減少10（投越多顆，減少越多）。 |
| 🍯 糖漿黏身 | 冒險 | 冒險戰鬥受到的傷害增加30%。 |

※冒險的初始活力最低為30，不會因為負面效果而低於30。
