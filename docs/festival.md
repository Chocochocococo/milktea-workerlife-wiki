# 節慶活動

遇到特定節慶時，奶茶店會舉辦限定活動。節慶期間以台灣時間為準，每年都會在同一個時間舉辦。

活動期間接客時，畫面底部會出現節慶活動的橫幅。

## 🎃 萬聖節
- 活動期間：每年10/20～11/03
- 限定內容：萬聖節限定客人、常駐客人的萬聖節裝扮、搗蛋小鬼、萬聖節南瓜轉蛋機、限定食材與限定茶譜

以下內容都只在萬聖節期間出現，活動結束後就要等明年了。

### 限定客人
萬聖節期間接客時，有機會遇到三位限定客人：

1. 南瓜頭先生：頭上套著一顆南瓜的紳士，說話時南瓜裡會透出燭光。
2. 吸血鬼伯爵：披著黑色斗篷、臉色蒼白的紳士，據說活了八百年。聽說他非常討厭大蒜。
3. 搗蛋小鬼們：一群披著床單、戴著紙面具的小孩。跟他們說今天賣完了，或是讓他們等到走掉的話，會被搗蛋並損失20～60奶茶幣。

限定客人一樣有好感度，升到「知己」時也會解鎖專屬稱號。所有客人的介紹請見[顧客一覽](list/customerlist.md)。

### 萬聖節裝扮
常駐客人有一半的機率會換上萬聖節裝扮來店裡，並說出萬聖節限定的需求。

### 萬聖節南瓜轉蛋機
1. 單抽200奶茶幣，十連抽1800奶茶幣。
2. 可以轉出限定食材「幽光南瓜泥」、「黑貓眼珍珠」，運氣好還能直接轉出「傑克南瓜珍珠拿鐵」。
3. 「傑克南瓜珍珠拿鐵」的食譜卡只有這台轉蛋機抽得到。

機率與獎品請見[轉蛋獎品一覽](list/gachalist.md)。

### 限定食材
1. 幽光南瓜泥、黑貓眼珍珠只能從萬聖節南瓜轉蛋機抽到，官方商店不賣，採購、冒險、寵物也不會帶回來。
2. 用不完的話，可以賣給官方商店，每個20奶茶幣。

### 傑克南瓜珍珠拿鐵
- 配方：幽光南瓜泥 x2、黑貓眼珍珠 x2、香醇牛奶 x1
- 恢復活力：150

1. 這道茶譜無法用`/研發茶譜`研發，只能從萬聖節南瓜轉蛋機抽到食譜卡學會。還沒學會之前也無法調製。
2. 還沒學會的人在萬聖節南瓜轉蛋機抽到傳說獎時，必定是食譜卡，所以最慢第100抽一定會學會。
3. 已經學會的人再抽到食譜卡，會換成幽光南瓜泥 x3、黑貓眼珍珠 x3。
4. 萬聖節結束後，已經學會的人只要還有限定食材，仍然可以調製；還沒學會的人就無法調製了。食譜卡與限定食材也只有活動期間抽得到。

### 萬聖節特調
萬聖節期間，把傑克南瓜珍珠拿鐵端給萬聖節的客人，會有特別的加成：

1. 萬聖節限定客人：不管點的是什麼，評分直接變成「😍 大滿意」，獲得的好感×2。
2. 穿著萬聖節裝扮的常駐客人：評分多升一級，獲得的好感×1.5。
3. 沒穿裝扮的常駐客人，或是萬聖節結束之後，就照一般口味評分，沒有加成。
